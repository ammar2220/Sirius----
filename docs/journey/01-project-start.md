# 01 - Project Start
**Date:** 2026-09-11
**Status:** Completed

## Overview
The Sirius project was initiated to develop a commercial-grade smart-home switch family for the Egyptian market. The goal is to create high-quality hardware and a companion app that emphasizes simplicity and intuitive UX.

## Goals
- Create a 1/2/3 channel switch family.
- Implement a no-neutral wire hardware approach.
- Develop a dedicated mobile app for control and provisioning.
- Target a local-first control architecture for V1.
