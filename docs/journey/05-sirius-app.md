# 05 - Sirius App Direction
**Date:** 2026-09-11
**Status:** In Progress

## Direction
The Sirius mobile application will be an independent product, not a clone of AION. It will take the high-quality UX elements of AION (cleanliness, simple room organization) and apply them to a local-first control architecture.

## Planned Integration
- Implementation of a local API client to communicate with the ESP32 prototype.
- Creation of a seamless onboarding flow that mimics the "Add Device" simplicity seen in benchmarks.
- Independent identity management using the hardware MAC address as the root of trust.
