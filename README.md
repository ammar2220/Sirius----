# Sirius Project README

## Overview
Sirius is a commercial smart-home product project focused on high-quality smart-switches for the Egyptian market. The project encompasses the design and implementation of ESP32-based hardware and a companion mobile application.

## Repository Organization
- `docs/`: All project documentation.
    - `docs/journey/`: Historical records of project milestones.
    - `docs/hardware/`: Hardware specifications and board designs.
    - `docs/firmware/`: API contracts and firmware documentation.
    - `docs/ux/`: User experience specifications and references.
- `firmware/`: ESP32 source code and build configurations.
- `mobile/`: Source code for the Sirius mobile application.
- `tests/`: Test suites and verification logs.
- `PROJECT_MEMORY.md`: The persistent source of truth for the project.
- `ROADMAP.md`: High-level project phases and tracking.
- `PRODUCT_REQUIREMENTS.md`: Defined product goals and constraints.

## Getting Started for Claude
To resume work on this project, follow these steps in order:
1. Read `PROJECT_MEMORY.md` to understand the current state and constraints.
2. Read `ROADMAP.md` to see the current phase and next tasks.
3. Inspect the current filesystem to verify the baseline.

**Crucial:** Do not perform any hardware flashes or firmware modifications without explicit approval.
